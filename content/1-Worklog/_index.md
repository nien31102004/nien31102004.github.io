During my internship at **Amazon Web Services Vietnam Co., Ltd.**, I completed a 12-week learning and project-development journey in the **First Cloud AI Journey** program under a hybrid working model.

The worklog below summarizes the main activities I carried out each week, including AWS foundational labs, infrastructure and identity services, data and AI topics, professional seminars, and the implementation of the group project **Secure AI-Driven Document Platform**.

In the project, I worked as the **Authentication & API Developer**, responsible for configuring Amazon Cognito, OAuth 2.0 Authorization Code Flow with PKCE, JWT authentication, Amazon API Gateway HTTP API, custom scopes, User/Admin groups, and access-control testing.

**Week 1:** [AWS account setup, program orientation, and AWS fundamentals](1.1-Week1/)

**Week 2:** [Core AWS services: IAM, VPC, EC2, S3, RDS, monitoring, and cost management](1.2-Week2/)

**Week 3:** [Building a private Amazon RDS environment inside a custom VPC](1.3-Week3/)

**Week 4:** [Provisioned EBS storage and internal data sharing with NFS](1.4-Week4/)

**Week 5:** [IAM Roles, AssumeRole, Trust Policies, and conditional access control](1.5-Week5/)

**Week 6:** [Technical seminars, Hackathon experience, confidence, and personal development](1.6-Week6/)

**Week 7:** [AWS Tags, Resource Groups, and resource management with AWS CLI](1.7-Week7/)

**Week 8:** [Billing delegation, IAM Identity Center, federation, and Permission Boundaries](1.8-Week8/)

**Week 9:** [Career development, mentorship, networking, system design, and caching](1.9-Week9/)

**Week 10:** [Modern Data Platform, Data Lake, ETL/ELT, QuickSight, and Data Governance](1.10-Week10/)

**Week 11:** [Project architecture review, Authentication & API documentation, testing, and demo preparation](1.11-Week11/)

**Week 12:** [AWS AI/ML services, Foundation Models, SageMaker, MLOps, and Responsible AI](1.12-Week12/)

Through these 12 weeks, I strengthened both my technical and professional skills. I gained practical experience in deploying AWS resources, securing APIs with JWT, applying role-based and scope-based authorization, working with team members, documenting technical work, and preparing an end-to-end project demonstration.
